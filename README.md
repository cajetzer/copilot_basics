# Practical GitHub Copilot Workshop

A self-contained, question-led presentation for developers learning to start, steer, and review GitHub Copilot tasks in VS Code, the GitHub Copilot app, GitHub.com, and the CLI.

Open `docs/index.html` in a browser to preview the presentation. Pick a topic or use the arrow keys to advance. Press **Home** to return to the topic picker and **N** to toggle presenter notes. The fictional tag-parser walkthrough requires no demo repository or Copilot sign-in. Copy buttons require browser clipboard access; if unavailable, select the prompt text manually.

The [facilitator guide](FACILITATOR-GUIDE.md) contains the agenda and troubleshooting references. Product features can vary by plan, policy, and execution environment.

Presentation content published at https://cajetzer.github.io/copilot_basics/
